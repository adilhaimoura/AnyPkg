# tests/trial — manual test ground

Drop anything you want to try here: downloaded .deb/.rpm/.pkg.tar.zst samples,
the trial dpkg shim, Electron-bundle samples, fixtures, notes...

Everything in this folder **except this README** is git-ignored (see `/.gitignore`),
so it will never be committed or pushed by accident. When something in here proves
good, copy the real thing into the repo proper, test it, then push the branch and
open a PR.
